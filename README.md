# crickbook
Cricbook is a web-based cricket scoring platform which allows user to create teams, do toss between teams, set the limit of overs, keep record ball-by-ball. It automatically manages scores, wickets, batsmen, bowlers and many other things to keep record of whole match.

Features
Interactive cricket scoreboard
 Display of match scores and statistics
Team and player information
Match-related controls and interactions
Responsive design for different screen sizes
Clean and modern user interface
 Fast client-side interactions using JavaScript
Bootstrap-based responsive components
GitHub integration
 Works directly in the browser without requiring a backend
